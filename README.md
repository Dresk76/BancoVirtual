# Simulador de Cajero Automático en C++

## Descripción

Este proyecto consiste en un **simulador de cajero automático desarrollado en C++**, realizado como parte del proceso de aprendizaje durante los estudios universitarios.

El programa se ejecuta en consola y permite simular diferentes operaciones básicas de un cajero automático, incluyendo el registro de usuario, autenticación mediante clave y gestión de transacciones bancarias.

El sistema inicia con un **saldo inicial de 1000 dólares** y permite al usuario interactuar con distintas funcionalidades financieras.

---

## Funcionalidades

El simulador incluye varias operaciones típicas de un cajero automático:

- Registro de usuario
- Ingreso de documento de identidad
- Registro opcional de correo electrónico
- Generación automática de una clave
- Posibilidad de cambiar la clave
- Ingreso de dinero
- Retiro de dinero
- Transferencias entre cuentas
- Validaciones de seguridad
- Simulación de diferentes tipos de cuentas y bancos

---

## Características técnicas

El proyecto utiliza varios conceptos fundamentales de programación en C++:

- Uso de **funciones**
- Manejo de **strings y arrays de caracteres**
- Validación de entradas del usuario
- Uso de **bibliotecas estándar de C++**
- Generación de números aleatorios
- Manejo de entrada de teclado con `getch()`
- Control de flujo con condicionales y ciclos
- Formateo de texto en consola con `iomanip`

## Objetivo del proyecto

El objetivo principal de este proyecto fue **practicar conceptos fundamentales de programación en C++**, tales como:

- Estructuración de programas grandes mediante funciones
- Manejo de datos ingresados por el usuario

- Organización de lógica de un sistema tipo menú
